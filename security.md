## 🎚️ Building A Profile That Stays Consistent

Consistency matters more than any single value. A player whose aim changes character
between sessions is more memorable than one whose aim is slightly assisted.

**Why profiles beat settings**

A profile is a saved set of every parameter, tied to a name. It means the aim behaves
identically in every session, on every map, at every range. Randomised or re-tuned
settings produce inconsistent behaviour, and inconsistency is what people notice.

**What a profile contains**

| **Group** | **Fields** |
| --- | --- |
| Targeting | bone, FOV, max distance |
| Motion | smoothing, reaction delay |
| Gating | visibility, team check, trigger mode |
| Output | curve shape, dead zone |

**Build three, not one**

| **Profile** | **Use** |
| --- | --- |
| Quiet | public matches, long sessions |
| Standard | normal play |
| Practice | offline or private only |

The practice profile is where you experiment. Keeping experiments out of the profile
you actually play with is what stops the aim drifting into obvious territory over a
few weeks.

**Switching, not editing**

Edit the practice profile, then copy it over the quiet one only when it has proven
itself. Editing the live profile mid-session is how a good setup slowly turns bad.

**The config is portable**

Profiles save beside the loader, so the whole folder can move between machines. That
also means the behaviour does not depend on the machine — only on the profile.

**Order of operations**

1. Close the game and its launcher completely.
2. Run the loader as administrator.
3. Open the **Spoofer** tab and press **Spoof**.
4. **Reboot** — volume serial and SMBIOS are read at boot.
5. Create a fresh account and log in.

**What it does not do**

It does not unban the old account. It gives the machine a new identity so a new
account is not linked to the old ban.

**Skipping the reboot is the most common mistake** — people report "the spoofer
did nothing" when they simply never restarted.
